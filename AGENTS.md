## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/`, one feature directory per effort. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its role name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` at the repo root plus ADRs under `docs/adr/`. See `docs/agents/domain.md`.
